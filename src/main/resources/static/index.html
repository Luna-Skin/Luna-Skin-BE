Luna Skin - 채팅 도메인 테스트

공통 설정

REST 요청은 X-USER-ID 헤더로, WebSocket 연결은 STOMP CONNECT 헤더로 아래 값을 사용합니다. "사용" 버튼을 누르면 채팅방 ID가 자동으로 채워집니다.

1. 채팅방 관리 (REST)

1-1. 채팅방 목록 조회 GET /api/chat/rooms 
    
  
    

  
    
    1-2. 채팅방 생성 POST /api/chat/rooms
    
    
    
    
    
    
    생성 성공 시 현재 채팅방 ID가 자동으로 채워집니다.
    
    
    
  
    

  
    
    1-3. 채팅방 이름 변경 PATCH /api/chat/rooms/{roomId}
    
    공통 설정의 "현재 채팅방 ID"를 대상으로 합니다.
    
    
    
    
    
    
  
    

  
    
    1-4. 채팅방 삭제 DELETE /api/chat/rooms/{roomId}
    
    공통 설정의 "현재 채팅방 ID"를 삭제합니다.
    
    
    
    
  
    

  
    
    1-5. 분석 기록 기반 채팅방 조회/생성 POST /api/chat/rooms/analyses/{analysisId}
    
    
    
    
    성공 시 현재 채팅방 ID가 자동으로 채워집니다.
    
    
    
  
    

  
    2. 대화 내역 조회 (REST)
    
  
    
    GET /api/chat/rooms/{roomId}/messages
    
    공통 설정의 "현재 채팅방 ID"를 대상으로 하며, 최신 메시지부터 반환됩니다.
    
    
    
    
    
    
    
      
    
      
  
      

  
      3. 파일/이미지 업로드 (REST)
      
  
      
    POST /api/chat/files
    
      공통 설정의 "현재 채팅방 ID"에 업로드합니다. 업로드 후 AI 응답도 함께 생성되어 브로드캐스트되므로, 아래 4번에서 연결해두면 실시간으로 확인할 수 있습니다.
      
    
      
    
    
        
    
        
  
        

  
        4. 실시간 채팅 (WebSocket / STOMP)
        

  
        
    연결 (/ws/chat)
    
        상태: 연결 안 됨
        
    
        공통 설정의 User ID / 현재 채팅방 ID를 사용해 연결합니다.
        
    
    
  
        

  
        
    메시지 전송 (/pub/chat/send)
